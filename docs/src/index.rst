Welcome to libtex documentation
==================================

Overview
--------

``libtex`` is a C library for writing `Latex <https://www.latex-project.org/>`_ ``.tex`` files,
designed to be a small utility library for C or C++ projects needing a standardized way
to write scientific reports with minimal code. ``libtex`` aims to provide features that
simplify document formatting and integration of external sources into the document.

Features
--------

- Convert Json files directly into Latex list environments.
- Retrieve author, date, and location details to save editing time.
- Generate Latex-compatible tables from row data or Csv input.
- Provide built-in plotting and advanced figure handling for Latex documents.
- Create Latex-compatible  `Tikz <https://www.overleaf.com/learn/latex/TikZ_package>`_ graphs directly from row input data.
